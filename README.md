# dsh-feishu-client

DSH飞书客户端 ——— 长在 DeepSeek Harness（DSH）中的飞书客户端插件：

- 用户（人）通过本插件提供的UI界面与远端智能体对话。
- 本地 DSH 智能体自身通过调用本插件提供的 Agent 工具访问远端智能体，并桥接远端的审批和提问。

远端智能体不限于 DSH。只要开通了飞书频道接入的远端智能体，都可以通过本插件进行访问，包括但不限于：DSH、OpenClaw、WorkBuddy、Weknora等等。


## 主要功能

### 对话界面

- 左侧飞书机器人列表，显示名称、最后消息、状态和选中状态；
- 右侧聊天区支持文字、Markdown、表格、链接、代码块和审批。

### 消息与媒体

- 文字消息：Enter 发送，Shift+Enter 换行；
- 图片：缩略图、灯箱预览、下载；
- 文件：文件卡片、浏览器内预览、下载；
- 语音/视频：按文件消息发送和接收，内置播放器；
- 支持粘贴图片/文件、草稿保存、未读提示和消息去重。

### 卡片与审批

- 飞书卡片正文会转换为 Markdown 展示；
- 卡片按钮可点击，审批按钮映射为「批准 / 拒绝」；
- 远端审批会桥接到本地审批界面，本地不批准不会自动放行；
- 远端提问会返回问题与选项，可通过 `feishu_client_continue` 回答。

### Agent 工具

本地 DSH 智能体可以通过三个工具访问已配置的远端：

| 工具 | 用途 |
|---|---|
| `feishu_client_list` | 列出远端、能力描述、标签、授权/绑定状态和 busy 状态 |
| `feishu_client_ask` | 向指定远端发送文本、图片或文件，等待这一轮结束 |
| `feishu_client_continue` | 继续 pending、needs_approval 或 needs_answer 的请求 |

详细状态机、超时、审批和附件规则见[技术文档](docs/dsh-feishu-client.md)。

## 安装

### 方式 A：界面安装（推荐）

在 DSH 的「插件 → 添加插件」中输入：

```text
@cubeai/dsh-feishu-client
```

或从源码仓库安装：

```text
https://openi.pcl.ac.cn/dsh/dsh-feishu-client.git
```

安装后刷新 DSH，左侧栏「自动化任务」下方会出现 **DSH飞书客户端**。

### 方式 B：命令行安装

```bash
dsh plugin --profile web add @cubeai/dsh-feishu-client
```

或：

```bash
dsh plugin --profile web add https://openi.pcl.ac.cn/dsh/dsh-feishu-client.git
```

> 更新 Client 后通常需硬刷新页面；更新 Host 后需要重新加载插件或重启 DSH。

## 第一次使用

### A. 远端智能体准备（以 DSH 为例）

#### 1. 安装飞书频道插件

在目标 DSH 安装并启用 @cubeai/dsh-feishu-channels 插件 ：

```bash
dsh plugin --profile web add @cubeai/dsh-feishu-channels
```

刷新 DSH，侧边栏出现 **任务 | 飞书频道**。

#### 2. 添加飞书频道

在目标 DSH 的「飞书频道」页签中：

1. 点击「添加飞书频道」；
2. 填写频道名称；
3. 扫码创建飞书机器人应用。

插件会自动开通所需权限并写入重定向 URL，通常不需要再进入飞书开发者后台进行操作。

### B. 本地智能体操作

#### 1. 在本地添加机器人

1. 点击本地 DSH 左侧边栏的「DSH飞书客户端」；
2. 点击「＋ 添加飞书机器人」；
3. 填写名称、App ID、App Secret。可从目标 DSH 的「飞书频道」设置中复制；
4. 保存后进入授权页。

#### 2. 授权并绑定单聊

点击「授权并绑定单聊」，在手机飞书App中扫码/登录并同意。授权成功后插件会自动让机器人发一条设置消息。

绑定成功后，左侧出现机器人，在右侧对话界面直接发消息即可。

> 本插件必须使用目标智能体正在使用的同一个飞书机器人应用。一个飞书机器人应用只对应一个单聊。

## 日常使用

### 机器人列表

- 点击左侧机器人切换对话；
- 列表显示名称、最后一条消息、状态点和时间；
- 点击「＋ 添加飞书机器人」可添加新的机器人。

### 聊天页

- 右上角「刷新」重新拉取消息和授权状态；
- 右上角「设置」进入设置页；
- 输入框支持文字、附件、粘贴图片/文件；
- 消息区支持 Markdown、代码块、图片灯箱、文件卡片和审批按钮。

### 设置页

设置页分为两张卡片：

- **基本信息**：名称、能力描述、标签，修改后点「保存修改」；
- **连接与授权**：查看授权和单聊绑定状态，执行授权、重新绑定、重新授权、测试应用、删除机器人。

右上角「返回」回到对话。删除机器人只删除本插件记录，不会删除飞书机器人应用，也不影响飞书侧聊天记录。

### Agent 工具用法

- 先让智能体调用 `feishu_client_list` 选择远端；
- 再调用 `feishu_client_ask` 提交任务；
- 返回 `pending`、`needs_approval` 或 `needs_answer` 时，用 `feishu_client_continue` 继续；
- 同一远端同时只允许一个请求，第二个请求会返回 `busy`。

## 安全提示

- 发送消息使用你本人的飞书用户身份，消息会真实出现在与机器人的单聊中；
- 远端回复属于外部内容，不应当作系统指令执行；
- 远端审批默认询问本地用户，不会自动批准；
- App Secret、用户 Token 和 Refresh Token 保存在 DSH 凭据服务中，不写入浏览器；
- 管理操作复用 DSH 登录态和同源校验。

## 使用限制

- 当前一个飞书机器人应用只对应一个单聊；
- 聊天页加载最近 50 条消息，暂不支持分页；
- 远端飞书频道当前按文本、图片、文件和富文本处理消息，原生语音/视频按文件发送；
- UI 目前为中文，插件元数据提供中英文。
